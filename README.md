## About

This repo is the code behind my portfolio. It covers my research, my clinical and professional experience, and my education.

It's plain HTML, CSS, and JavaScript with no framework and no build step, so GitHub Pages serves the files exactly as they are.

## Features

| Feature | Why |
| --- | --- |
| **Clean and readable** | Navy and teal on white, with a serif for headings |
| **Gentle motion** | Subtle fade-ins that switch off if your device asks for reduced motion |
| **Phone-friendly** | Built to read well on small screens |
| **Accessible** | A skip link, keyboard-friendly menu, focus styles, and readable color contrast |
| **Shares nicely** | Link previews, structured data for search, a sitemap, and a custom 404 page |

## Files

```
index.html              the page itself
404.html                where you land if a link is wrong
Tommy-Li-Resume.pdf     my résumé
assets/css/styles.css   all the styles
assets/js/main.js       menu, fade-ins, and the copy-email button
assets/img/             my photo and the link-preview image
assets/icons/           favicons and app icons
```

The rest of the root is the small stuff browsers and search engines look for: `favicon.ico`, `apple-touch-icon.png`, `site.webmanifest`, `robots.txt`, `sitemap.xml`, and `.nojekyll`.
